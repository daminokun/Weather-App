# Weather App

A real-time weather application built with HTML5, CSS3, and JavaScript using the OpenWeatherMap API.

---

## Live Demo
Access the live app:
https://daminokun.github.io/Weather-App/

---

## Features
- **Real-Time Weather Data**: Displays temperature, humidity, and wind speed.
- **Search by City**: Query weather data for any global city.
- **Error Handling**: Displays feedback when an invalid city name is entered.

---

## Tech Stack
- HTML5 & CSS3
- JavaScript (`fetch`, `async/await`, DOM Manipulation)
- OpenWeatherMap REST API
